# Известные ограничения MVP

1. В проекте нет импорта банковских операций, расширенной аналитики и автоматической отмены услуг у поставщика.
2. Для запуска нужны установленные Django, Psycopg и PostgreSQL; зависимости не включены в архив.
3. SQL-модель из практики 6 подключается как физическая схема; полноценные Django-миграции для нее в этой учебной версии не создаются.
4. Планирование и средняя нагрузка вычисляются в браузере по данным API; отдельные платежные строки не хранятся.
5. Нагрузочное тестирование, реальная матрица браузеров, HTTPS, резервное копирование архивов и RPO/RTO требуют отдельного прогона после развертывания.
6. Демо-пользователь и пароль предназначены только для локальной учебной базы.
