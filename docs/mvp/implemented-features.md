# Реализованные функции MVP

| Функция | Приоритет | Критерий готовности |
|---|---|---|
| Вход в личный кабинет | Обязательная | Сервер проверяет пароль и создает сессию; без входа личные данные не выдаются. |
| Просмотр личных подписок | Обязательная | Данные читаются из PostgreSQL по владельцу и отображаются прежним интерфейсом. |
| Добавление подписки | Обязательная | API проверяет поля, создает subscription и первую condition_version в одной транзакции. |
| Категории | Обязательная | Категория сохраняется с владельцем; повтор названия возвращает ошибку. |
| Изменение условий | Обязательная | Новая версия сохраняется отдельной строкой; история не переписывается. |
| Календарь и расходы | Обязательная | Прежняя расчетная модель интерфейса строит даты, план и среднюю нагрузку по данным сервера. |
| Отключение учета | Обязательная | Сервер устанавливает дату отключения и исключает будущие события. |
| Удаление подписки | Обязательная | Сервер удаляет запись владельца и связанные версии по FK CASCADE. |
| Понятные ошибки | Обязательная | Возвращаются сообщения для обязательных полей, формата, дубликата, отсутствия записи и ошибки сохранения. |
| Импорт, аналитика и банковские операции | Не входит в MVP | Перенесены на последующую версию Premium. |

Интерфейс оставлен по практической работе 7: изменена только логика обмена данными с сервером.
